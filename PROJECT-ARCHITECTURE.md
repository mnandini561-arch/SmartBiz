# SmartBiz - Business Management System

## 1. Project Objective

Develop a full-stack Business Management System using
Angular, ASP.NET Core Web API, C#, and SQL Server.

## 2. Technology Stack

- Frontend: Angular
- Language: TypeScript
- Backend: ASP.NET Core Web API
- Backend Language: C#
- Framework: .NET 8
- Database: SQL Server
- ORM: Entity Framework Core
- Version Control: Git

## 3. Planned Modules

1. Authentication
2. Authorization
3. Dashboard
4. Department Management
5. Employee Management
6. Customer Management
7. Product Management
8. Order Management
9. User Management
10. Audit Logs
